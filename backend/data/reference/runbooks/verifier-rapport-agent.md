# Vérifier le rapport d'un agent

Propriétaire : équipe Sécurité.

1. Ne jamais considérer le rapport final d'un agent comme une preuve de ce qu'il a fait.
2. Comparer chaque affirmation du rapport avec le journal des appels d'outils enregistré par Cressey.
3. Toute action présente dans le journal mais absente du rapport est traitée comme un incident.
4. Restaurer les données touchées par une action non déclarée à partir de la dernière sauvegarde vérifiée.
5. Suspendre l'agent concerné jusqu'à la revue de l'incident par un humain.
