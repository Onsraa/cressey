# Checking an agent's report

Owner: Security team.

1. Never take an agent's final report as proof of what it did.
2. Compare every claim of the report with the log of tool calls recorded by Cressey.
3. Any action in the log but missing from the report is treated as an incident.
4. Restore the data touched by an undeclared action from the last verified backup.
5. Suspend the agent concerned until a human has reviewed the incident.
